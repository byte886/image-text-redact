# 敏感词分类词库与扩词指南

> 被 `../SKILL.md` 按需引用：整理脱敏词表、判断哪些词该糊、如何扩充时读这里。

## 核心认知
1. **没有万能敏感词表**：内置 PII 正则只覆盖跨场景通用的个人信息；主题敏感词（金融监管、暴力、行业措辞等）必须按具体内容定制。
2. **等长替换是零残字的关键**：一个字符换一个 █，排版不变；直接在位图上打码容易残留半个字、误伤邻字，所以有源文本一定走文本路线重绘。
3. **中性词不要误伤**：如金融语境里“汇款/额度/账户/现金/出境/流水/风控/买房”是中性词，不应糊；要糊的是“地下汇款/资金外逃”这类组合语义。拿不准就只糊用户明确点名的词与其近义词。

## 一、内置已自动覆盖（无需写进词表）
手机号、身份证号、银行卡号、邮箱、IPv4。脚本按正则识别并等长遮盖，且刻意不遮年份、短数字、普通金额。QQ号/微信号/详细地址/姓名因易误伤不自动处理，需要时写进词表。

## 二、分类词库模板（按需复制成 words.txt，每行一个，# 注释）
提示：长词/组合词放前面（脚本也会按长度自动排序），先糊组合短语再糊单词，避免“地下”先被替换导致“地下汇款”匹配不到。

```text
# —— 个人 / 隐私（内置正则之外的）——
真实姓名
具体单位名称
家庭住址、门牌号
微信号、QQ号、订单号、车牌号

# —— 金融监管 / 非法资金（示例，按内容取舍）——
地下汇款、地下钱庄、对敲、资金外逃、资本外逃
洗钱、毒资、蚂蚁搬家、轮卡取款
空壳公司、假合同、虚构贸易
USDT、稳定币、买 U、U 链
恐慌溢价、资本外流、跨境套现

# —— 涉毒 / 涉赌 / 涉暴 / 涉黑 ——
（按实际内容列具体词，避免单列高频单字误伤）

# —— 商业机密 ——
未公开金额、客户名单、内部代号、合同底价、密钥/Token
```

## 三、扩词方法（保证“这类词”都糊干净）
1. 先让用户给**定性范围**（如“监管类、情绪类、某行业类”），而不是零散单词。
2. 围绕每个核心词补三类：
   - **同义/近义**：地下汇款 ≈ 地下汇兑、私下换汇、对敲；
   - **上下游组合**：恐慌 → 恐慌溢价、恐慌性外流；
   - **写法变体**：带空格（“买 U”“U 链”）、中英文混排、缩写（USDT/Tether）、大小写。
3. 不确定平台审核口径时，检索该平台社区规则/审核案例核对分类（哪些属高危、哪些是正常金融词），并把来源记下来。
4. 跑完先看脚本输出的“命中处数”和脱敏稿，再通读一遍：漏的补词重跑，误伤的从词表删掉。

## 四、两条技术路线对比

| 维度 | 路线 A：源文本等长替换+重绘（首选） | 路线 B：位图 OCR+色块（兜底） |
|---|---|---|
| 前提 | 有 MD/TXT 源文档 | 只有一张图片 |
| 残字风险 | 无（字符级替换） | 可能残留半字，需放大复核 |
| 邻字误伤 | 无 | OCR 框估算可能偏，需外扩/回读 |
| 产物 | 脱敏 MD + 可选 PNG 长图 | 直接在图上盖色块 |
| 工具 | 标准库 + 本机 Chrome 渲染 | macOS Vision(swift) + Pillow |

## 五、渲染与字体注意
- 长图用本机 Chrome/Edge headless 渲染，`--force-device-scale-factor=2` 出高清；找不到浏览器只产出文本、跳过 PNG。
- 若改用 Python(PIL) 直接往图上写中文标签，macOS 用 `/System/Library/Fonts/STHeiti Medium.ttc`；PIL 默认字体不含中文，`PingFang.ttc` 在部分沙箱 Python 下打不开。
- 替换字符默认 █；需要弱化而非全遮时可换 ■、▢、【已脱敏】（注意非等长会改变排版宽度，等长场景仍用单字符）。
